الآن مع ضابط الشبكة – حجب وتحديد الأجهزة، قفل البرنامج، أيقونة Tray، اكتشاف الشبكات المجاورة، والتعرف على MAC العشوائي.

لقطات الشاشة

استعرض جميع أقسام البرنامج

أدوات شبكية متكاملة

اكتشاف الأجهزة الذكي

فحص سريع أو شامل مع كشف MAC العشوائي، أسماء الأجهزة الحقيقية، والشبكات المجاورة.

📡 ضابط الشبكة

حجب الإنترنت وتحديد النطاق الترددي. مؤقتات، تأجيل رفع الحجب، استمرارية في الخلفية، وحماية ذاتية.

فحص المنافذ المتقدم

اتصالات نشطة مع أسماء البرامج و PID. تبويبان للاتصالات والاستماع، فحص nmap للأجهزة البعيدة.

تشخيص DNS و Traceroute

اختبار خوادم DNS، تتبع المسار، Ping متقدم مع إحصائيات ورسائل توضيحية.

قياس سرعة الإنترنت

مقياسان دائريان متحركان بقيم حية. حفظ آخر نتيجة وعرضها تلقائياً.

واجهة عربية/إنجليزية

RTL كامل، قفل البرنامج، أيقونة Tray، شاشة ترحيب، وتحسين استهلاك الذاكرة.

النسخة الطرفية v0.1

لمحبي سطر الأوامر. أوامر منفصلة مع نسخ سريع.

git clone https://github.com/gnutux/GT-IpNet.git

استنساخ المستودع

cd GT-IpNet && chmod +x gtipnet.sh

إعداد الصلاحيات

sudo ./gtipnet.sh

تشغيل البرنامج

./gtipnet.sh --scan
